# DevPortfolio

Personal portfolio website showcasing my frontend projects, skills, and experience.

**Live site:** https://portfolio-omega-bice-25.vercel.app

## Tech Stack

- React 19
- Next.js
- TypeScript
- Tailwind CSS v4
- Lucide Icons

## Features

- Responsive design across desktop and mobile
- Project showcase with live demo and GitHub links
- Downloadable resume
- Direct contact via email
- Optimized for performance and SEO

## Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/HemanthBhat15/Portfolio.git
cd Portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
